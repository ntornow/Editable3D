# Surface control-grid editing

`SurfaceEdit` edits independent positive-weight `NURBS.surface` and unique-control `Cyclic.surface` descriptors. It creates no native objects or scene instances. Controls use `control[i][j]`, with U indexing rows and V indexing columns. All returned grids, weights and basis arrays are independent copies; the source remains unchanged on success, rejection or cancellation. Degree remains in 1–8, and each direction needs more controls than its degree.

Point and weight edits retain the basis. Structural edits rebuild the changed direction's basis and generally change the surface over its entire parameter domain. For refinement that preserves the evaluated shape and parameterization, use `NURBS.insertSurfaceKnot`, `splitSurface`, degree elevation/removal, or the corresponding periodic `Cyclic` functions. Extracting a control rectangle is not extracting a parameter rectangle.

The callable editing families follow the control-grid behaviors described in Blender's [surface editing](https://docs.blender.org/manual/en/5.0/modeling/surfaces/editing/surface.html) and [control point editing](https://docs.blender.org/manual/en/5.0/modeling/surfaces/editing/control_points.html) documentation. Selection UI, object parenting and editor interaction are outside this headless API. This package additionally preserves explicit nonuniform rational bases in unchanged grid directions.

## Selection and point edits

Control masks are dictionaries with canonical, one-based `"i:j"` keys. Values are booleans or finite numbers in [0,1]. A supplied mask treats missing keys as zero; no mask selects every control. Missing controls and noncanonical keys such as `"01:1"` reject. `invertMask` replaces each weight with one minus its value, and finite `strength` multiplies it. Point/weight interpolation permits signed strength, provided the resulting descriptor remains finite with positive weights.

`select(surface, selector?, options?)` returns a mask only. A selector is a predicate `(point, weight, i, j) -> boolean | number`, or a table with inclusive `u` and `v` Vector2 index ranges, `boundary = "all" | "U0" | "U1" | "V0" | "V1"`, and an optional predicate. These constraints intersect, then multiply the options mask and strength. Returned weights must remain in [0,1]. `"all"` includes only actual open borders; naming a border in a cyclic direction rejects. Unclamped open directions still have control borders.

| Function | Behavior |
| --- | --- |
| `map(surface, operation, options?)` | Calls `(point, weight, i, j) -> point, weight?` for nonzero influence. Omitted returned weight retains the old one. Blends both outputs by the control influence. |
| `transform(surface, frame, options?)` | Applies `pivot + frame:VectorToWorldSpace((point-pivot)*scale) + frame.Position`, then blends. `scale` defaults to `Vector3.one`, `pivot` to zero. Negative scale supports mirroring. |
| `setWeights(surface, values, options?)` | Accepts a positive constant, sparse control dictionary, or `(weight, i, j, point) -> positiveNumber?`. Missing dictionary entries or nil callback results retain the weight. `mode="multiply"` interprets values as factors; default `"set"` uses target weights. |
| `smooth(surface, iterations?, options?)` | Simultaneous four-neighbor grid smoothing, with distinct wrapped neighbors in cyclic directions. Defaults: one iteration, `factor=0.5`, `pinBoundary=true`, `smoothWeights=false`. Open boundary controls stay fixed unless unpinned. |
| `deform(surface, operation, options?)` | Supplies an independent point-only `Mesh` and a `"i:j" -> vertexId` map to an existing mesh deformation callback. The callback returns the posed mesh and optional operator report. Outer surface masks blend the result. |

Smoothing requires `factor * influence` in [0,1]. It averages control positions and, optionally, rational weights; it is not an area/curvature minimizing surface fairing solve. Unique periodic controls are updated once, including seam controls. Point transforms and `map` can express snapping, displacement, local hook influences and other procedural edits without attaching scene objects.

The deformation bridge stores rational weights in the numeric vertex channel `surface_weight`. Callbacks must retain this channel's schema, all original vertex IDs, the vertex count and an empty face set. Every returned point and rational weight is validated, including masked-out controls. Reports with `complete=false`, `success=false` or `converged=false` reject. A callback may mutate its temporary mesh. It must manage its own internal work budget and cancellation; the adapter cannot bound arbitrary user code. Point-only deformation functions such as `Deform.shear`, local-frame simple deformation and custom point maps can be composed through this bridge; surface-dependent mesh solvers still require their own face topology.

## Grid structure

Axes are `"U"` or `"V"`. Borders are `"U0"`, `"U1"`, `"V0"`, `"V1"`; only open directions have borders. Structural functions operate on complete rows or columns, not an arbitrary point mask. Their `options.mask`, `invertMask` and `strength` do not change which rows are edited; use the explicit ranges/indices or edit callback for that choice.

`duplicate(surface, uRange?, vRange?, options?)` copies an inclusive rectangular control subgrid. Omitted ranges span the full direction. A full, unaltered direction retains its knots or cyclic intervals. A sliced direction becomes open, uniformly knotted and clamped. `degreeU`/`degreeV` override degree; `reduceDegree=true` lowers it to at most count−1 when necessary. Explicit `knotsU`/`knotsV` and `clampedU`/`clampedV` apply only to a rebuilt direction. One-row/column results reject because they are curves, not tensor-product surfaces.

`transpose(surface, options?)` swaps control indices, degrees, weights, knots, intervals and cyclic/clamped flags. The result evaluates as `old(v,u)`; the ordered derivative cross product reverses orientation. This is an exact parameter swap, not a geometric reflection.

`setCyclic(surface, axis, enabled, options?)` retains the unique controls and weights while replacing the selected direction's basis. Enabling defaults to equal periodic intervals; `intervals` supplies a different valid pattern. Disabling defaults to a uniform clamped basis, with optional `knots` and `clamped=false`. Already having the requested state returns a basis-preserving copy and ignores basis overrides. This authoring toggle changes shape. Use `Cyclic.surfaceToNURBS` to expand a periodic descriptor without changing its evaluated shape.

`extrude(surface, boundary, steps?, operation?, options?)` appends complete control sections at an open border. It defaults to one step. A Vector3 is the per-step translation; a CFrame transforms the previous section; a callback `(point, weight, step, profileIndex) -> point, weight?` computes it. Each new section uses the preceding section, and prepended sections are ordered from newest to the old border. Nil operation duplicates sections without movement. Existing controls and weights are retained exactly. The edited direction receives a uniform basis of its existing degree and clamping convention, unless `degree`, `knots` or `clamped` overrides it. Zero steps return an unchanged copy. The other direction retains its complete basis, including cyclic intervals. This operation does not preserve the original evaluated surface as a subpatch.

`split(surface, axis, index, options?)` returns two independent surface descriptors in an array and a report. An open grid duplicates the shared interior row: rows 1..index and index..count. A cyclic grid splits its ring into 1..index and index..count followed by row 1; both pieces open the split direction, including a split at the last unique row. Both seam rows are independent copies. Piece degrees and rebuilt bases use the same options as `duplicate`. Too few rows reject unless `reduceDegree` or an explicit degree makes every piece valid.

`deleteRows(surface, axis, indices, options?)` removes the specified unique row indices and bridges the remaining grid. It retains cyclic state and regenerates the changed direction's uniform basis. `degree`, `reduceDegree`, `knots`, `intervals`, and `clamped` customize that direction. Duplicate/missing row indices reject. Empty indices return an unchanged copy.

`deleteSegments(surface, axis, first, last, options?)` removes connections between increasing control-row endpoints, preserving the endpoints. An open grid returns pieces 1..first and last..count. A cyclic grid returns one opened piece ordered last..count, 1..first. Interior rows are removed, without bridging across the gap. Piece basis options match `duplicate`. Every remnant must be a valid surface with at least two rows; requests that would leave a curve-only remnant reject. Extract such a border with `boundaryCurve` and explicitly delete the remaining rows when that mixed curve/surface result is desired.

## Borders and spin

`boundaryCurve(surface, boundary, options?)` returns an independent rational or unique cyclic curve, retaining the border control positions, weights and the profile direction's basis. On a clamped border it is the surface's geometric edge. On an unclamped border it is the control-row curve, not generally the evaluated isoparametric edge; use `NURBS.isoCurve` for the latter.

`spin(surface, boundary, origin, axis, angle, options?)` constructs a new surface by revolving that border profile about a finite origin and nonzero axis. It does not append to the source patch. `startAngle` defaults to zero; angles are radians, nonzero and at most one full turn in magnitude. U follows the profile, V follows the revolution. Profile knots or unique cyclic intervals and rational weights are retained; the rational quadratic circular direction supplies exact circular arcs up to native coordinate rounding. A full turn within 1e−12 uses eight unique periodic controls and cyclic V, avoiding duplicate seam controls. A partial turn uses an open quadratic basis. A cyclic profile can therefore produce a surface cyclic in both directions. Profiles on the axis can create collapsed poles; subsequent tessellation needs its usual pole options. `Surfaces.revolve` remains available for ordinary curve inputs.

## Reports, limits and verification

All edits except `select` and `boundaryCurve` return a result and report. `split` and `deleteSegments` return an array of patches. Reports include `complete`, `sourceControls`, `controls`, `work`, and `sourceRefs` mapping output control keys to original control keys (one map per patch for array results). Extrusion adds `created` and `createdControls`; spin repeats border source references. Point edits report modified control/weight counts and maximum displacement. Structural edits report `basisChanged`, and splits list shared source rows. A complete report certifies descriptor construction only: `regularityChecked=false` explicitly excludes surface injectivity, self-intersection, tangent regularity or patch continuity guarantees.

Common limits default to `maxControls=10000` expanded controls (including periodic degree padding), and `maxWork=2000000` counted control visits. Extrusion defaults to `maxSteps=128`; smoothing to `maxIterations=1000`. `cancelled()` and `checkpoint({stage,work})` run at begin/end and during counted work, approximately every 256 visits. Invalid data, exhausted budgets and cancellation throw without mutating the source. These are allocation/iteration bounds, not wall-clock guarantees. Larger explicit edit limits do not override independent limits of downstream NURBS evaluation or tessellation APIs; their documented limits still apply.

Twenty-five regression cases cover independent rational evaluation and affine transformations, canonical masks, cyclic seam edits, common weight scaling, simultaneous smoothing, callback isolation, every extrusion border, unclamped/nonuniform bases, shared split borders including the last periodic row, deletion semantics, exact circular geometry, native closed-mesh UV seams, positive weights, cancellation and budgets. `Examples.ControlNetPanel` combines extrusion, weighted transforms, weight editing, smoothing and an existing mesh deformation before tessellation.
